# Dávid László Szekeres · Portfolio

Architecture and design portfolio: a static site built with three.js and GSAP.

Live: https://szeki02.github.io/szekeres-portfolio/

## Run locally

The site is plain HTML, CSS and JavaScript modules, so any static file server works. On Windows:

```
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```

then open http://localhost:8767/.
